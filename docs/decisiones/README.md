# Decisiones

Cada decisión importante queda en un archivo numerado, para que dentro de seis meses se sepa qué se decidió y por qué.

- Un archivo por decisión: `NNNN-tema.md`, con el número siguiente.
- Entra por pull request, como todo. Si una decisión cambia, no se borra: se agrega una nueva que la reemplaza y se marca la vieja como reemplazada.
- Formato: fecha, estado, decisión, por qué, qué implica y qué se descartó.
